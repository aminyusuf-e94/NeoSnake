# 🐍 NEON SNAKE: CYBERRUN

Game 2D Arcade bertema Cyberpunk yang dibangun menggunakan Python dan `pygame-ce`.

## 🌟 Fitur Utama
- **Visual Cyberpunk Neon:** Efek pendaran (*Glow Effects*) menggunakan *Alpha Blending* dan animasi grid.
- **Procedural Audio Engine:** Efek suara (SFX) dan musik latar (BGM Synthwave) dibuat secara otomatis melalui algoritma matematika Python (`wave` & `struct`) tanpa aset eksternal.
- **Arsitektur Clean Code:** Menggunakan pola *Object-Oriented Programming* (OOP) dan *State Machine*.
